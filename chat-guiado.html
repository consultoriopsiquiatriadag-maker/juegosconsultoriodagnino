Chat de Apoyo Guiado

Escribí lo que te pasa o elegí una opción. Este chat propone ejercicios breves de respiración, mindfulness y orientación a recursos del sitio.

No guarda datos personales, no realiza diagnósticos y no reemplaza la consulta médica. Supervisado por el Dr. Pedro Nicolas Dagnino.

Tip: probá empezar con una frase simple (“Estoy muy activado”, “Estoy triste”, “Estoy cansado”, “Estoy esperando turno”).

Privacidad

Este chat está pensado como apoyo breve. No guarda tus mensajes, no pide datos personales y no reemplaza la consulta médica. Si estás en una situación de emergencia, buscá ayuda presencial en tu sistema local.

Este recurso puede registrar estadísticas anónimas de uso (por ejemplo, qué herramientas se eligen) para mejorar la sala de espera virtual. No se guardan conversaciones completas ni datos personales.

¿Qué más podés hacer desde acá?

Si estás en riesgo

Si estás en riesgo o necesitás ayuda inmediata, no uses este chat como único recurso. Comunicate con emergencias locales, una guardia o una persona de confianza.
