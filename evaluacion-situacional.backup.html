Cómo funciona

Tres pasos simples, sin vueltas.

1
Coordinación
La secretaría coordina por WhatsApp fecha, consentimiento y modalidad.
2
Entrevista + test (si corresponde)
Una o más entrevistas. Se indican test sólo si aportan claridad clínica.
3
Devolución escrita
Recibís un documento claro con síntesis, hipótesis y próximos pasos.
Qué incluye y qué no incluye

Incluye

  • Entrevista clínica (una o más).
  • Test cuando corresponde.
  • Integración clínica.
  • Devolución escrita.
  • Opción de informe técnico para profesional tratante.

No incluye

  • Urgencias.
  • Seguimiento.
  • Recetas/indicaciones farmacológicas por este canal.

¿Cuál es el objetivo de este dispositivo?

Este dispositivo ha sido creado para evaluar el momento actual y entregar una devolución escrita, útil para vos y/o para tu profesional tratante. Es similar a lo que clásicamente se conocía como segunda opinión; en este caso tiene un plus: permite que una persona, en donde se encuentre, pueda tener una segunda mirada con un informe que permita trazar una hoja de ruta para su salud mental.

Tip: si estás en un lugar tranquilo, podés usar lectura por voz para entender el contenido sin esfuerzo.
