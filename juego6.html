Búsqueda visual

Encontrá el símbolo objetivo entre los distractores. Duración sugerida: 2 a 5 minutos.

Objetivo: encontrar el símbolo objetivo lo más rápido posible

Cómo funciona: aparece una grilla de símbolos con un objetivo indicado arriba. Tocá el símbolo correcto. La grilla crece con el nivel.

Objetivo

★ (tocá el objetivo)

Tocá "Iniciar" para comenzar.

Este ejercicio tiene fines de estimulación cognitiva general. No constituye una evaluación diagnóstica ni un test psicológico.

Cómo funciona

  • Hay un símbolo objetivo y varios distractores.
  • Tocá el objetivo lo más rápido posible.
  • La grilla crece con el nivel.

Sugerencia breve

Buscá ritmo y precisión. Si hay cansancio visual, hacé una pausa corta y retomá más tarde.

Accesibilidad

Letras grandes y botones amplios. Si el dispositivo reduce animaciones, el juego mantiene el funcionamiento.
